## ⚠️ THE TRAP — read before touching git

`git status` currently reports **every tracked file in the repository** as modified —
hundreds of them, including all of `supabase/migrations/`, `package-lock.json` and every
test. **This is not real.** It is a CRLF/LF line-ending artefact:

```
git diff HEAD --ignore-cr-at-eol --stat
→ 2 files changed, 139 insertions(+), 2 deletions(-)
```

Only those two files have actual content changes. Therefore:

- **NEVER** `git add -A`, `git add .`, or `git commit -a`. Stage by explicit path.
- **NEVER** `git checkout HEAD -- .` — it would delete the 139 lines above.
- Do not "fix" the line endings and do not add `.gitattributes`. That is a separate
  decision I have not asked for. `core.autocrlf` was set to `true` locally during the
  domain move; the ghost diff comes and goes and is not worth chasing.
- Prefer `git --no-optional-locks` for read-only git commands: an ordinary `git status`
  from a mounted folder once left a stale `.git/index.lock` that blocked all commits.

# Hard constraints — never propose anything that breaks these

- **No budget, ever.** Supabase **Free** (500 MB DB / 1 GB storage / 5 GB egress, project
  pauses after ~1 week idle) and Vercel **Hobby** (one cron slot, already used by
  `/api/health`; single function region; non-commercial). No paid service, no new vendor
  account, now or later.
- **Anonymous reading always works** — browsing, reading and search need no account.
- **RTL Uyghur UI**; code, comments and commit messages in English.
- **Mobile quality equals desktop quality.** The Mobile Rules in `CLAUDE.md` are hard
  requirements: `100dvh` never bare `100vh`, safe-area padding, ≥44 px targets, no
  horizontal scroll at 360 px, no fixed bar that swallows a control, logical properties
  for RTL, and every feature tested at **375×667, 390×844 and 1280×800**.
- **No PDF and no OCR on the web.** Accepted: `.docx`, `.doc`, `.md`, `.html`, `.txt`,
  web URL. Never propose re-adding `pdfjs-dist` or a browser OCR library.
- **Search operators are permanently removed.** No quoted phrases, no `OR`, no
  `-exclusion`. Whatever is typed is one literal phrase.
- **AI is bring-your-own-key and browser-only.** Each signed-in reader supplies their own
  Gemini key; it stays in their browser and goes straight to Google. It never reaches my
  server and is never stored in Supabase. Strict model selection — failover changes the
  key, never the model. I pay nothing. There is no `GEMINI_API_KEY`.
- **RLS on every table**; `/admin` and every mutating Server Action re-verify the role
  server-side.
- **Never edit an applied migration** — always add a new file in `supabase/migrations/`.
- **Do not weaken the CSP**; no third-party runtime scripts or CDNs.
- **Never delete** `bilim-hezinisi-website.vercel.app` from Vercel, the old address from
  Supabase's Redirect URLs, or the Google `TXT` record from Hostinger.
- The desktop repo is a **read-only reference**.
